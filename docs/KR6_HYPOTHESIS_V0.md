## 0. 등록 상태 (먼저 읽을 것)

- 이번 작업은 사용자 명시 지시(2026-10-21 KR-6 V0 지시서)에 따른 설계다. AGENTS.md 우선순위상 사용자 지시가 앞선다.
- 그러나 등록부 수정은 이번 범위가 아니다(기존 파일 수정 금지). **KR-6을 등록부에 올릴지는 사용자 결정**이다. 등록 전까지 KR-6은 Census를 시작하지 않는다.
- 현재 프로젝트 단계는 Phase 0(`PHASE_0_COMPLETE = NO`)이다. 이 문서는 신호·수익률을 계산하지 않는다.

## 1. 연구 질문

변동성이 일정 기간 축소된 KOSPI·KOSDAQ 보통주가, 압축 구간의 고점을 종가로 돌파하면서 거래대금이 함께 늘어날 때, 다음 거래일 시가에 들어가 5·10·20거래일 보유한 수익률이 **비용 차감 후** 적절한 비교군을 초과하는가?

## 2. 가설

| 기호 | 내용 |
|---|---|
| H1 (주가설) | 압축 + 돌파 + 거래대금 확장 신호(주 사양 `KR6-P`) 이후 10거래일 순초과수익(비교군 C3 대비, BASE 비용)이 0보다 크다 |
| H2 (기여 가설) | 같은 돌파·거래대금 조건에서 **압축이 있는** 신호가 압축이 없는 돌파(C1)보다 나쁘지 않다. 즉 압축 조건이 정보를 더한다 |
| H0 (귀무) | 신호 이후 순초과수익은 0 이하다 |
| H_alt (경쟁 가설) | 한국 시장, 특히 KOSDAQ 중소형주에서 거래대금 급증일은 개인 관심 집중에 따른 **단기 반전**이 지배한다. 이 경우 돌파 다음 날 시가 진입은 음의 초과수익을 낸다 |

H1만 맞고 H2가 틀리면 "돌파+거래대금 효과"는 있을 수 있으나 **KR-6의 가설(압축이 핵심)은 기각**이다. 그 효과를 KR-6 V0의 성공으로 보고하지 않는다.

## 3. 기대하는 시장 현상

1. **변동성 군집과 평균회귀**: 변동성은 낮은 구간 다음에 확장되는 경향이 있다. 다만 이것은 **크기**(절댓값)에 대한 주장이지 방향에 대한 주장이 아니다.
2. **방향 정보는 돌파와 거래대금에서 온다**: 좁은 가격대에서 매물이 소화된 뒤 상단을 넘으면 공급이 얇아진다는 가설. 거래대금 동반은 새 참여자 진입의 대리 지표다.
3. **정보 확산 지연**: 돌파가 공개 정보(공시·실적)의 지연 반영이라면 며칠에 걸쳐 이어질 수 있다. 이 연구는 공시를 쓰지 않으므로 이 경로를 구분하지 못한다(Review 문서 2절).

이 세 가지는 동기일 뿐 검증 대상은 H1·H2다. 메커니즘 설명을 결과로 보고하지 않는다.

## 4. 대상 Universe (요약, 정의는 Census 설계 2절)

- 시장: KOSPI, KOSDAQ. KONEX 제외.
- 종목: 신호일 t 기준 상장된 **보통주 주권**. 우선주, 리츠, 투자회사, 사회간접자본투융자회사, 외국주권, 주식예탁증권, ETF·ETN, 스팩 제외.
- 신호일 t에 상장되어 있었다면 **이후 상장폐지·합병·시장 이전된 종목도 포함**한다. 오늘 상장된 목록을 과거에 적용하지 않는다.
- 기간: 신호 2019-01-02 ~ 최신 확정 거래일. 지표 계산용 워밍업 원시 데이터는 2017-08-01부터.
- 신호가 나지 않은 종목을 Universe에서 지우지 않는다. 비교군(C2, C3)과 시장 동일가중 벤치마크(C0a)가 이들로 구성된다.

## 5. 주 사양 KR6-P (사전등록, Census 전 고정)

정확한 식은 Census 설계 3절. 여기서는 요지만 둔다.

| 요소 | 주 사양 |
|---|---|
| 압축 | 40거래일 고저 범위비율 `RR_40`이 자기 과거 252거래일 값 중 하위 20% 이하 |
| 돌파 | 신호일 종가 > 직전 40거래일(신호일 제외) 최고가 |
| 거래대금 | 신호일 거래대금 ≥ 직전 20거래일 평균의 2.0배 |
| 유동성 | 직전 20거래일 평균 거래대금 ≥ 5억원, 신호일 종가 ≥ 1,000원 |
| 진입 | 신호 다음 거래일 시가(시가 단일가 시장가 매수 가정). 체결 판정은 개장 전 정보와 시가 단일가 결과로만 하고 그날 고가·저가·종가는 쓰지 않는다. 체결 불가면 미체결, 시가 상한가처럼 체결 여부를 알 수 없으면 미확정 항목으로 두고 판정 인증으로 처리. 대체 체결·이월 진입 없음 (Census 5.1, 5.6) |
| 주 평가 기간 | 10거래일(5·20은 보조) |
| 손익 | 원시 체결가와 보유 원장(주식 수·현금 흐름)으로 계산. 보유 중 사건으로 거래를 지우지 않고, 매도할 수 없던 자산을 마지막 가격으로 소급 청산하지 않는다. 증명 가능한 평가가 없는 자산은 수치 구간을 대입하지 않고 UNRESOLVED로 둔다. 교부·신설 주식은 실제 매도 가능일 `σ`가 확인된 뒤에만 매도한다. (V0.5) 같은 ISIN으로 추가상장되는 신주는 매도 전에도 그 ISIN의 관측 종가로 일별 평가하고, 최종 금액 상한이 확정된 권리·현금채권은 `[0, 상한]`으로 평가한다. 매도 시점과 이벤트 손익 규칙은 그대로다 (Census 5.3, 5.3a, 5.4) |
| 비교 | C3 매칭 비교군(같은 날·같은 시장·시총 3분위 × 과거 60일 수익률 5분위, Census 7.1) |
| 중복 | 같은 종목은 신호 후 20거래일 동안 새 신호를 세지 않음 |

이 사양은 결과를 보기 전에 고정한다. Census에서 다른 사양이 더 좋아 보여도 V0의 판정 대상은 KR6-P 하나다.

## 6. 반증 조건

아래 중 하나라도 해당하면 **KR-6 V0 = FAIL, CLOSED**. FAIL 뒤 임계값을 바꿔 다시 시도하지 않는다(FAIL RESCUE 금지). 새 아이디어는 다음 가설 버전으로 별도 사전등록한다(8절).

| 코드 | 반증 조건 (연구 구간 2019~2022, KR6-P, h=10, BASE 비용) |
|---|---|
| F1 | 캘린더 타임 포트폴리오의 C3 대비 일평균 순초과수익 ≤ 0, 또는 Newey-West t < 2.0 |
| F2 | 이벤트 단위 C3 대비 순초과수익 **중앙값** ≤ 0 |
| F3 | C1(비압축 돌파) 대비 평균 총초과수익 < 0 (압축이 정보를 더하지 않음 → H2 기각) |
| F4 | 연구 구간 4개 연도 중 순초과수익 양수인 연도가 3개 미만, 또는 한 연도가 전체 누적 초과수익의 50% 초과, 또는 이벤트 50개 이상인 시장의 순초과수익 점추정 < 0 |
| F5 | 신호일 상한가 마감 이벤트를 빼면 캘린더 타임 평균 순초과수익 ≤ 0 (효과가 상한가 이벤트에만 있음) |
| F6 | 검증 구간(2023~2024)에서 순초과수익 ≤ 0 또는 t < 1.5 |
| F7 | Holdout(2025~)에서 순초과수익 ≤ 0 (1회만 계산) |

데이터 Gate가 하나라도 PASS(또는 데이터 계약 6절이 허용한 N/A)가 아니면 FAIL이 아니라 **BLOCKED**다. 데이터가 없는 것을 가설 기각으로 보고하지 않는다.

판정 인증 원칙(V0.2에서 V0.1의 "8개 경계 시나리오" 원칙을 대체, V0.3에서 포괄성 전제와 식별자 규칙 추가): 일봉으로 정할 수 없는 값(시가 상한가 진입, 종가 하한가 청산과 그 일부 체결, 증명된 구간만 있는 자산 가치)은 이벤트·구성원·시도일마다 **독립된 미확정 항목**이다. 신호와 비교 대상(C1·C3·C0a)의 체결 불확실성도 서로 묶지 않는다. 위 반증 조건과 Census 9.2의 PASS 조건은 **허용 가능한 모든 경로**(Census 5.6의 경로 집합 Ω)에서 같은 결론임을 Census 5.6의 인증 방법으로 증명했을 때만 확정한다. 증명하지 못하면 FAIL도 PASS도 아닌 BLOCKED다. 8개 시나리오는 제한된 민감도 분석(묘사)일 뿐 모든 결과의 상한·하한이 아니며, 수익률의 경계를 Newey-West t나 연도 기여도의 경계로 쓰지 않는다. 증명 가능한 평가가 없는 자산(회수 불명, 분류 불가 기업행위 등)은 UNRESOLVED이며 근거 없는 수치 구간으로 대체하지 않는다. V0.3: (1) 인증은 미확정 항목 목록과 이벤트별 평가 상태 트리가 규칙에서 기계적으로 전개되었음이 증명된 경로에서만 한다. 평가 상태가 바뀌는 경로의 끝점 열거를 전체 경로의 극값으로 주장하지 않으며, 증명하지 못하면 BLOCKED다. (2) 식별자가 확정되지 않은 행이 신호 생성, 쿨다운, 비교군 선정에 영향을 줄 수 있으면 포함·제외 가정으로 메우지 않고 해당 계산을 인증하지 않는다(BLOCKED, Census 2.5). V0.4: (3) 무영향 증명은 당일 부적격이 아니라 판독 범위 전체의 부적격과 교부 자산 계보 밖임을 요구하고, 결측(`DATA_MISSING`)도 같은 규칙으로 다룬다(신호 없음으로 확정하지 않음, B-MISS, Census 2.5·2.6). (4) 관측되지 않은 일별 수익률을 0%로 두지 않는다. 평가 불가 기간은 증명 가능한 값 집합으로만 다루고, 누적 손익(이벤트 단위)과 일별 통계(캘린더 타임)를 분리한다(Census 8.2). (V0.5) 예외는 확인된 거래정지의 평가액 유지(정지 묶음, 측정창 끝까지)뿐이며 일별 평가 관례로만 쓴다. 이 예외는 사용자 결정 U21로 상태가 PROVISIONAL이고, 결정 전에는 판정을 확정하지 않는다(Census 8.2). (5) 판정 통계량이 모든 경로에서 정의되는지 먼저 인증하고, 정의되지 않는 경로는 증거가 있을 때만 B-STAT, 배제하지 못하면 B-BOUND다(Census 5.6). (6) 현재 단계는 RESEARCH 컷오프(2022-12-29) 뒤 시장 데이터를 수집·열람·품질 분석하지 않으며 HOLDOUT은 별도 해제 절차 뒤에만 연다(데이터 계약 4.1). V0.5: (7) 정상적인 시장 사건 때문에 `T_cens`까지 끝나지 않은 경제적 미종결은 판정 전체를 BLOCKED로 만들지 않고, 이벤트를 지우거나 임의로 청산하지 않은 채 손익 범위로 조건별 인증에 전파한다. 데이터 결함(결측, 미해소 식별자, 분류 불가 기업행위)으로 생긴 미종결만 B-UNRESOLVED다(Census 9.1, 9.1a). (8) NXT 범위 확인(2025-03-04 이후)은 Census 조건이 아니라 Contract Freeze 조건 D6H다. HOLDOUT 잠금은 그대로다(데이터 계약 6절). 임계값(0, 2.0, 1.5, 50%, 3개 연도, 이벤트 50개)은 바꾸지 않았다.

## 7. 이 가설이 주장하지 않는 것

- 실제 매매 수익. 운영 가능성(주문 경로, 체결, 용량)은 따로 판정한다.
- 상장 후 약 240거래일(약 11~12개월) 미만 종목(워밍업 부족으로 구조적으로 제외, Census 2.3)에 대한 결론. (V0 초안의 "약 14개월"은 정정)
- 현금배당을 포함한 총수익. KR-6 수익률은 가격수익률이다(데이터 계약 3.4).
- KR-1(가격 압축 + 거래대금 + 투자자 수급)에 대한 결론. KR-6은 수급을 쓰지 않는다. KR-6 결과로 KR-1을 PASS·FAIL 처리하지 않는다.

## 8. 버전 명명 규칙 (V0.1, V0.2 보완)

두 종류의 "버전"을 섞지 않는다.

| 종류 | 표기 | 뜻 | 허용 조건 |
|---|---|---|---|
| 문서 개정 | `V0.1`, `V0.2`, … (파일명은 `*_V0.md` 유지) | 같은 가설 KR-6 V0의 계약 문구를 고치는 것. 결함 수정, 정의 보완 | KR-6 데이터(신호·수익률·분포)를 하나도 보기 전에만. 가설, 주 사양, 판정 임계값, 구간을 바꾸면 문서 개정이 아니다 |
| 가설 버전 | V0 다음의 가설 버전(번호 체계는 아래 미결 충돌, 사용자 결정). 새 파일 | 다른 가설·사양·임계값. V0의 FAIL 뒤 새 아이디어, 보조 사양 승격 | 사전등록 + 아직 쓰지 않은 구간에서만 검증 |

- 판정 표기는 가설 버전을 따른다: `KR6_V0 = PASS / FAIL / BLOCKED`. 문서 개정 번호는 판정 이름에 붙지 않는다.
- 이번 개정 작업의 지시서 이름 "KR6 V1 REPAIR"의 V1은 **수정 작업 회차**다. 가설 KR-6 V1이 아니다. 결과 문서는 V0.1 개정이다. V0.2 지시서(KR-6 V0.2 계약 결함 집중 수정), V0.3 지시서(KR-6 V0.3 계약 집중 수정), V0.4 지시서(KR-6 V0.4 통합 결함 수정)의 결과도 같은 가설 V0의 문서 개정이다.
- **미결 충돌 (V0.2, 사용자 결정 U14)**: RESEARCH_RULES 5절은 "V1 FAIL이면 V1 CLOSED, 새 가설은 V2"라고 적는다. KR-6은 V0에서 시작하므로 이 문구가 KR-6에 어떻게 적용되는지(V0 다음 가설 번호, 등록부 문구 개정 여부)는 이 문서가 정하지 않는다. V0.1의 "다음 정수 버전이라는 뜻으로 적용한다, 다음 가설 버전은 V1"은 상위 규칙을 임의로 재해석한 것이라 철회했다. 사용자가 정할 때까지 V0 다음 가설에 번호를 붙이지 않고 "다음 가설 버전"이라고만 쓴다. 이 충돌은 V0 자체의 판정 표기와, FAIL한 가설은 CLOSED라는 원칙에는 영향을 주지 않는다.
