# P0 V2-B 역사적 투자자 수급 확보 가능성 결과

작성일: 2026-10-21 · 모델: Claude Opus 5.5 (claude-opus-5-5) · 범위: S2(키움·KIS 수급 API), S3(KRX 유료 원장)

## 0. 요약

- **실제 API 호출: 0회.** KR-B 전용 인증정보가 없다(`KRB_*` 환경변수 0개, `config/sources.toml`·`.env` 없음). 지시대로 새로 발급하거나 US-B에서 복사하지 않고 실호출 단계를 **BLOCKED**로 둔다.
- 공식 명세는 확인했다. 키움 `ka10059`와 KIS `FHPTJ04160001` 모두 **종목별·투자자 세부유형별·KRX/NXT/통합 구분** 수급을 준다(문서 기준).
- **두 API 모두 "가장 오래된 조회 가능일"과 "한 번에 몇 행을 주는지"를 공식 문서 어디에도 적지 않았다.** 날짜 파라미터는 "기준일"이고, 그 날짜부터 과거로 연속조회하는 구조다. 2019년까지 되는지는 실호출로만 알 수 있다.
- **KIS `FHPTJ04160001`은 모의투자 미지원**이다(포털 명시). S2를 KIS로 하려면 실전 계좌 앱키가 필요하다.
- KRX 데이터 마켓플레이스에는 **주식 "투자자별 거래실적" 판매 상품**이 공식 목록에 있다. 종목별인지, 기간·가격·이용조건은 **로그인 뒤에만** 보인다(UNKNOWN). 구매 시 "이용목적 심사"가 있다.
- KRX/코스콤 정보이용정책서(2024-01-01)는 **실시간 정보를 자동·알고리즘 매매에 쓰는 것을 "비조회형 정보이용"으로 분류해 신고·별도 이용료 대상으로 둔다.** 개인이 증권사 API를 통해 받는 경우에도 적용되는지는 UNKNOWN이다. 연구(과거 EOD 데이터)와 LIVE 운영(실시간)의 라이선스 쟁점이 다르다.

```text
KR_INVESTOR_FLOW_SOURCE        = PARTIAL
KR_HISTORICAL_BULK_FEASIBILITY = BLOCKED   (검증 차단: 인증정보 없음. "불가능" 판정이 아님)
S2_COMPLETE                    = NO        (명세 확인 완료, 실호출 미실행)
S3_COMPLETE                    = NO        (공개 자료 조사 완료, 상품 상세·가격은 로그인/문의 필요)
PHASE_0_COMPLETE               = NO
```

### 2.1 키움 `ka10059` 종목별투자자기관별요청

| 항목 | 명세 |
|---|---|
| 경로 | POST `https://api.kiwoom.com/api/dostk/stkinfo`, 헤더 `api-id: ka10059` |
| 모의 도메인 | `mockapi.kiwoom.com` 표기 있음. 이 TR의 모의 지원 여부는 명세에 없음(오류코드 8104 "모의투자에서 지원하지 않는 API" 존재) |
| 요청 | `dt`(일자 YYYYMMDD, 필수), `stk_cd`(KRX `039490` / NXT `039490_NX` / SOR `039490_AL`), `amt_qty_tp`(1 금액 / 2 수량), `trde_tp`(0 순매수 / 1 매수 / 2 매도), `unit_tp`(1000 천주 / 1 단주) |
| 응답 | 목록 `stk_invsr_orgn`: `dt`, 현재가, 등락, 누적거래량, 누적거래대금 + 투자자 13개 |
| 투자자 | 개인, 외국인, 기관계, 금융투자, 보험, 투신, 기타금융, 은행, 연기금등, 사모펀드, 국가, 기타법인, 내외국인 |
| 단위 | 금액 백만원, 수량 천주 또는 1주 |
| 연속조회 | 응답 헤더 `cont-yn=Y`면 `next-key`로 다음 페이지. 공식 예제는 `dt`부터 과거 날짜 순(내림차순) 응답 |
| 행 수/페이지 | **명세 없음** |
| 가장 오래된 날짜 | **명세 없음** |
| 금액과 수량 | 둘 다 제공하지만 **호출을 따로** 해야 함(`amt_qty_tp`) |
| 호출 제한 | 공식 수치 없음. 오류코드 1700/1701/1702(요청 개수 초과)만 있고, 공식 예제 간격은 0.2초 |

### 2.2 KIS `FHPTJ04160001` 종목별 투자자매매동향(일별)

| 항목 | 명세 |
|---|---|
| 경로 | GET `/uapi/domestic-stock/v1/quotations/investor-trade-by-stock-daily` (실전 `openapi.koreainvestment.com:9443`) |
| **모의투자** | **미지원**(포털: "모의 Domain 모의투자 미지원", "모의 TR ID 모의투자 미지원") |
| 요청 | `FID_COND_MRKT_DIV_CODE`(J KRX / NX NXT / UN 통합), `FID_INPUT_ISCD`(6자리), `FID_INPUT_DATE_1`(기준일), `FID_ORG_ADJ_PRC`(공란), `FID_ETC_CLS_CODE` |

| 응답 | `output1`(현재가 요약), `output2`(배열: 영업일자, OHLC, 거래량·대금 + 투자자별 순매수·매수·매도의 수량과 대금) |
| 투자자 | 외국인(+ 등록/비등록 분리), 개인, 기관계, 증권, 투자신탁, 사모펀드, 은행, 보험, 종금, 기금, 기타, 기타법인, 기타단체 |
| 단위 | 금액 백만원, 수량 주 |
| 금액과 수량 | **한 번의 호출에 둘 다** |
| 연속조회 | 헤더 `tr_cont`: 응답이 M이면 다음 요청에 N |
| 행 수/페이지 | **명세 없음** |
| 가장 오래된 날짜 | **명세 없음** |
| 당일 데이터 | "15:40 이후 가집계·산출, 산출 시간대는 일정하지 않을 수 있음", "00:00~15:40 이외 시간은 당일 조회 제한"(원문 그대로, 의미 불명확) |
| 호출 제한 | 포털 오류코드 `EGW00201` 초당 거래건수 초과. 수치는 공식 GitHub 구버전 예제 주석 "REST 1초당 20건", 현행 `smart_sleep` 실전 0.05초·모의 0.5초 |

참고: GitHub 예제의 연속조회 재귀 호출은 인자 순서가 어긋나 있다(`tr_cont` 자리에 데이터프레임이 들어감). 예제 코드를 연속조회 동작의 근거로 쓰지 않는다.

## 4. 항목별 판정

| 항목 | 판정 | 근거 |
|---|---|---|
| HISTORICAL_DEPTH | **UNKNOWN** | 두 API 모두 깊이 명세 없음. 실호출 BLOCKED. KRX 상품 기간은 로그인 뒤 |
| INVESTOR_COVERAGE | **PARTIAL** | 필수 4유형과 기관 세부가 두 명세에 모두 있음. 문서 확인일 뿐 실호출 검증 아님. 두 증권사의 기관 분류 체계가 서로 다름(예: 키움 "연기금등" vs KIS "기금", KIS "기타단체" 별도) |
| UNIVERSE_COVERAGE | **UNKNOWN** | 상폐 종목 조회 근거 없음. 단축코드 재사용 시 다른 종목을 잡을 위험(V1) 유지 |
| PIT_USABILITY | **PARTIAL** | 당일분은 15:40 이후 가집계(KIS). 확정 시각 공식 공지 없음. 두 API 모두 정정 이력 필드 없음 → 지금 받는 과거 값이 당시 값인지 확인 불가. 2023-12 외국인 등록제 폐지로 KIS 등록/비등록 구분의 의미가 바뀌었을 가능성 [추정] |
| LICENSE | **UNKNOWN** | KIS 개인 본인 투자 목적은 허용 [문서]. 원본 영구 저장은 두 증권사 모두 미확인. 키움 이용약관 미열람. 코스콤 정책서의 비조회형(자동매매) 신고 조항이 개인 API 이용자에게 적용되는지 UNKNOWN |
| BULK_FEASIBILITY | **UNKNOWN** | 행 수·깊이·상폐 지원이 모두 미확인이라 계산 불가. 아래는 가정 기반 참고치 |

**종합: `KR_INVESTOR_FLOW_SOURCE = PARTIAL`.** 필요한 필드가 있는 공식 경로는 문서로 확인됐다. 하지만 2019년 깊이, 상폐, 정정, 저장 허용이 하나도 입증되지 않았다. 데이터가 존재한다는 것과 백테스트가 가능하다는 것은 별개다.

## 6. 대안 검토 순서

1. **S2 실호출**(키움 또는 KIS): 깊이·상폐가 되면 가장 싸고 빠른 경로.
2. **KRX 유료 원장**: 로그인해서 "투자자별 거래실적" 상품 상세를 보거나 데이터사업부에 문의.
3. **정식 라이선스 데이터 업체**: 이번에 조사하지 않음(UNKNOWN). 2번이 막히면 다음 단계에서 조사.
4. **기타 공식 기관**: 해당 없음 확인(데이터 라이브러리는 학술 전용).

금지 유지: KRX 정보데이터시스템 로그인 세션 모방, pykrx 등 비공식 스크래핑, 약관에 반하는 자동 수집.

KR-1은 종료하지 않는다. 다만 위 1·2가 모두 실패하면 KR-1은 "Forward 누적 후 연구"로만 남는다는 점을 숨기지 않는다.

## 7. 사용자 조치

### 7.1 S2 실호출을 위해

- 둘 중 하나 이상: **키움 REST API 앱키**(실전 또는 모의. 모의에서 ka10059가 되는지도 확인 대상) / **KIS 실전 계좌 앱키**(이 TR은 모의 미지원)
- KR-B 환경변수로 직접 주입: `KRB_KIWOOM_APP_KEY`, `KRB_KIWOOM_APP_SECRET` / `KRB_KIS_APP_KEY`, `KRB_KIS_APP_SECRET`, `KRB_KIS_ACCOUNT_NO`. US-B 키를 KR-B가 복사하지 않는다(같은 계정을 쓸지는 사용자가 결정).
- 참고: `config/sources.example.toml`의 KIS 기본값은 `environment = "paper"`인데 이 TR은 모의에서 안 된다. 실행 시 실전 환경으로 따로 설정해야 한다.
- 표본 종목 B(KOSDAQ 중소형)를 지정하고, 종목 C(상폐)를 KIND 화면에서 직접 확인해 확정한다.
- 증권사 이용약관에서 "조회한 시세의 로컬 저장"과 "본인 투자 연구 이용"이 허용되는지 확인한다(아래 문의 문안).
