### 3.4 정정·삭제 이력

- 허브 보고서: **변경은 별도 행**으로 나온다(같은 계약번호, 계약변경차수 증가, 그 행의 계약일자 = 변경일). `최종계약여부`는 조회 시점 기준으로 계산된 값으로 보인다(2019-01-02 행 중 N 163) [실측, 계산 시점은 추정].
- **삭제 이력은 허브 보고서에 없다.** 삭제된 계약이 과거 조회에서 사라지는지 남는지 UNKNOWN.
- OpenAPI에는 계약변경이력·계약삭제이력 오퍼레이션이 있다 [문서]. 키가 있어야 확인 가능.

### 3.5 기간 표기 불일치

data.go.kr 계약 OpenAPI 페이지는 "시간범위 2004년 7월 - 2025년 1월"이라고 적는데, 허브는 2026-10-20 계약까지 준다 [실측]. API 메타데이터가 갱신되지 않았거나 API와 허브의 범위가 다를 수 있다. API 자체의 2025-02 이후 제공 여부는 여전히 UNKNOWN.

2002-01 행 수(625)가 2004-06(2,391)보다 훨씬 적다. 나라장터 전면 개통 이전 기간의 수록 범위가 다를 수 있다 [추정]. 연구 기간은 2019년 이후로 잡을 계획이므로 직접 영향은 작다.

**판정: PROCUREMENT_PUBLIC_SAMPLE = AVAILABLE, PROCUREMENT_HISTORICAL_DEPTH = PARTIAL.** VERIFIED가 아닌 이유: 5개 지점만 봤고, 날짜별 완전성(예: OpenAPI·나라장터 공개 화면과 건수 대조)을 확인하지 않았다.
