# Phase 0 V2 실데이터 표본 검증 계획

작성일: 2026-10-21. 상태: **계획만. API 호출 0건.** 실행은 사용자 승인 후.

## 0. 공통 규칙

- 각 테스트는 1회성 소량 호출이다. 최대 호출 수를 넘기면 즉시 멈추고 보고한다.
- 실행 위치는 로컬(`/home/tjd618/krb`). 운영 서버·US-B 자원을 쓰지 않는다.
- 인증정보는 KR-B 환경변수(`config/sources.example.toml`의 이름)로만 주입한다. US-B 키를 복사하지 않는다.
- 응답 원본은 `data/raw/p0v2/<테스트>/<retrieved_at>/`에 그대로 저장하고 sha256을 남긴다(gitignore).
- 판정 문서는 `reports/P0_V2_<테스트>.md`로 남긴다(추적).
- 주문 API, 유료 결제, 대량 수집은 하지 않는다.
- 이용조건이 UNKNOWN인 소스는 약관을 먼저 확인하고, 금지면 호출하지 않는다.
- 결과를 보고 PASS 조건을 바꾸지 않는다.

## 실행 순서와 승인 단위

1. 사용자: 키 발급(KRX Open API, data.go.kr, OpenDART, 키움 또는 KIS) + 종목 B 지정 + 종목 C 확정 + S3 문의
2. 승인 후 S2 → S1 → S4 → S5 → S6 순으로 각 1회 실행 (S3는 사람이 병행)
3. 각 테스트 결과를 `reports/`에 판정 문서로 남기고 SOURCE_REGISTER 갱신
4. 전체 결과로 `FIRST_RESEARCH_CANDIDATE` 재판정 ([RESEARCH_RULES.md](RESEARCH_RULES.md) 3절 규칙 그대로)

표본 검증 코드를 쓰게 되면 그때 `pyproject.toml`에 필요한 의존성만 추가하고, 호출 상한을 코드에 고정한다.
