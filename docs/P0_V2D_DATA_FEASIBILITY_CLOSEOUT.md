# P0 V2-D 데이터 확보 가능성 조사 마감

작성일: 2026-10-21 · 모드: 읽기 전용 조사 + 보고 · 구현·수집·백테스트 없음
대상: KR-1 KR-ACCUMULATION-SURGE, KR-2 KR-CONTRACT-EVENT, KR-3 KR-TURNAROUND-BREAKOUT
전략 정의는 [RESEARCH_RULES.md](RESEARCH_RULES.md) 2절 그대로 둔다. 이 문서는 정의를 바꾸지 않는다.

## 1. Executive Summary

- 공개자료로 확인할 수 있는 범위는 거의 다 확인했다. 남은 질문은 **인증키, KRX 로그인, 기관 답변** 없이는 풀리지 않는다.
- **어느 전략도 데이터 확보 가능성이 입증되지 않았다.**
  - **KR-1**: 핵심인 종목별 투자자 수급의 2019년 이후 깊이와 상장폐지 종목 포함 여부가 하나도 실측되지 않았다. 판정은 증권사 키 또는 KRX 답변을 기다려야 한다. **BLOCKED.**
  - **KR-2**: 조달 계약 실데이터(사업자번호 포함)는 인증 없이 받을 수 있다. 그러나 핵심인 "조달 사건의 최초 공개시각"이 어느 공식 자료에도 없다. 이번에 확인한 법령(시행령 제92조의2, 시행규칙 제82조)도 공개 **항목**만 정하고 공개 **기한**은 정하지 않는다. **PARTIAL**, PIT = UNRESOLVED.
  - **KR-3**: 가격·상장종목 마스터(KRX OpenAPI, 2010~)와 재무(OpenDART, 2015~) 경로는 공식 문서로 확인됐다. 수급이 KR-1과 같은 이유로 미확인이다. 원형 그대로 **PARTIAL**.
- V2-D에서 새로 얻은 공식 근거 4건:
  1. KRX OpenAPI 일별매매정보·종목기본정보는 과거 날짜를 넣으면 **그날 유효했던 종목**을 고르는 구조다(공개 명세에 포함된 API 정의, 실호출 아님).
  2. 같은 API의 가격은 **수정주가가 아닌 원시 OHLC**이고, 최근 거래일 데이터는 **다음 날 08시 이후** 나온다.
  3. OpenDART 단일회사 전체 재무제표는 "2015년 이후 부터 정보제공".
  4. 국가계약법 시행령·시행규칙에 계약체결 정보 **공개 기한 조항이 없다**.

```text
KR1_DATA_FEASIBILITY       = BLOCKED
KR2_DATA_FEASIBILITY       = PARTIAL
KR3_DATA_FEASIBILITY       = PARTIAL
RESEARCH_EFFORT_COMPLETE   = YES   (현재 허용된 공개자료 범위 기준)
DATA_FEASIBILITY_CONFIRMED = NO
PHASE_0_COMPLETE           = NO
```

## 2. 실제 사용 모델

Claude Opus 5.5 (`claude-opus-5-5`), Claude Code만 사용.

V2-D 외부 요청: curl 7건, 헤드리스 브라우저 세션 5회(law.go.kr 4, KIND 1), WebSearch 5회. 인증·로그인·서비스키·증권사 API·결제는 모두 0건이다. 근거 사본은 `data/raw/p0v2d/public_20261021/`(gitignore, SHA256SUMS·SOURCES.txt 포함)에 있고, 개인정보는 없다.

KRX 정보데이터시스템(data.krx.co.kr)은 V2-C에서 헤드리스 접근이 차단됐으므로 이번에는 접근하지 않았다. 같은 실패를 반복하지 않았다.

## 10. 데이터 확보 가능성에 대한 최종 결론

- **RESEARCH_EFFORT_COMPLETE = YES.** 현재 허용된 범위(공식 공개자료, 허용된 공개 표본, 인증 없음, 로그인 없음, 차단 회피 없음)는 소진됐다. 남은 질문은 전부 다음 중 하나가 필요하다: 인증키, KRX 로그인(사람), 기관 답변. 예외로, 공개자료로 더 할 수 있지만 하지 않은 것이 2가지 있다.
  - (1) 지방계약법 공개 조항 확인: 저비용, KR-2 판정을 바꾸지 않음.
  - (2) 허브 날짜별 연속 조회로 2019~ 연속성 확인: 사실상 대량 조회라 이번 범위 밖이고, 허브 자동수집 조항이 UNKNOWN.
- **DATA_FEASIBILITY_CONFIRMED = NO.** 실데이터로 입증된 것은 조달 계약 접근과 매핑 키뿐이다. 세 전략 모두 정의상 필수 조건이 하나 이상 미입증이다.
  - KR-1·KR-3: 종목별 수급
  - KR-2: 최초 공개시각

기관 확인 없이는 결론을 낼 수 없는 질문:

1. 조달 사건 최초 공개시각과 rgstDt의 의미 → **KR-2 PIT의 성패를 가른다**
2. KRX 판매상품의 종목별 여부와 범위 → KR-1·KR-3 과거 수급
3. 증권사 수급 TR의 과거 깊이·상폐 → KR-1·KR-3 (키가 있으면 실호출로도 확인 가능)
4. KRX OpenAPI 상폐 포함과 NXT 범위 → 전 전략 Universe (키가 있으면 실호출로 일부 확인 가능)
5. KRX OpenAPI "비상업" 범위, 증권사 데이터 저장 허용 → 전 전략의 운영 가능성

첫 연구 후보 규칙(RESEARCH_RULES 3절)을 적용하면, P0-1은 미검증이고 P0-2도 "검증"이 아니므로 **FIRST_RESEARCH_CANDIDATE = UNDECIDED가 유지된다.** Census를 시작하지 않는다.

## 12. 검증하지 못한 사실

- 종목별 수급: 2019년 깊이, 상폐 종목, 페이지 크기, 정정 이력, 확정 시각, 저장 허용(키움·KIS·KRX 모두)
- KRX 판매상품: 종목별 여부, 기간, 항목, 가격, 이용조건
- KRX OpenAPI: 실제 응답에 상폐 종목이 있는지, NXT 포함 여부, 수정주가 경로, "비상업" 범위
- 조달: 2019~ 연속성, 낙찰 실데이터, rgstDt 실제 값과 의미, 삭제 이력 내용, 최초 공개시각, 허브 자동조회 허용
- 매핑: 대량 적중률, 지점 번호 변환, 상폐 상장사 corp_code, 합병·개명 이력
- DART: 2019~2023 분 단위 접수 시각의 공식 대량 경로, 정정공시 연결 규칙
- KIND 이용약관
- 지방계약법 공개 조항
- 분할·병합·감자 이벤트 공식 목록

## 13. 추가 인증정보가 필요한 항목
